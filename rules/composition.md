## C1. 构图的唯一目的是把视线引到主体

```yaml
id: COMP-001
rule: 构图不是目的本身，其基本任务是把观众视线引导到你想突出的主体上。
why: 人眼视觉本能；任何与主体争夺注意力的元素都是干扰。
how: 主体不突出、视线被边缘杂物抢走时，裁掉干扰物、把主体放到视觉落点上，而非生硬套三分法。
source:
  - NYIP《Three Guidelines》注意力引向主体（已查证）：https://www.nyip.edu/photo-articles/photography-tutorials/three-guidelines-for-great-photographs
  - NYIP 豆瓣读书第8课8问（已查证）：https://book.douban.com/subject/1007928/blockquotes
  - wuwu composition.md（一方称）：https://www.iesdouyin.com/share/video/7637402569190427910 ；https://www.iesdouyin.com/share/video/7642245523788909865
evidence: NYIP 已查证 + wuwu 一方称 → 多源支撑，构图目的论可作硬规则。
```

## C2. 三分法与趣味中心

```yaml
id: COMP-002
rule: 画面九等分，主体或关键细节（眼睛、焦点）放四个交叉点之一，比居中更和谐。
why: 三分点接近黄金分割，避免上下/左右绝对对等，制造韵律。
how: 主体贴边或居中呆板时，把主体挪到四个三分交叉点之一；新手先开相机九宫格辅助线。
source:
  - NYIP《The Rule of Thirds》（已查证）：https://www.nyip.edu/photo-articles/photography-tutorials/the-rule-of-thirds
  - NYIP 豆瓣读书笔记第8章（已查证）：https://book.douban.com/annotation/75651566/
  - wuwu composition.md（一方称）：https://www.iesdouyin.com/share/video/7631487948302634283
evidence: NYIP 已查证 + wuwu 一方称 → 多源支撑。
```

## C3. 主体位置弹性：居中/三分/边缘

```yaml
id: COMP-003
rule: 三分之一只是默认而非铁律——居中传达稳定庄严，放边缘传达拘谨压迫，三分点传达平衡。
why: 位置服务于情绪和意图；规则是起点，熟练后应主动打破。
how: 要表现极简单主体（落日、单主体风光、双人合照）可大胆居中；要表现拘谨/压迫把主体顶到边缘；默认平衡再用三分点。
source:
  - NYIP 主体位置弹性（已查证）：https://book.douban.com/annotation/75651566/ ；https://book.douban.com/subject/1007928/blockquotes

evidence: NYIP 已查证 + wuwu 一方称 → 多源支撑。
```

## C4. 黄金分割视觉落点：左上起点、右下停留

```yaml
id: COMP-004
rule: 四个焦点里重点用两个——左上角是人眼视觉起点（第一眼落处），右下角是视觉停留/结束点；重要主体放左上，耐看意境放右下。
why: 人眼黄斑区最清晰处偏左上，看东西先落左上；右下停留更久、更有记忆点。
how: 人像脸想让观众第一眼看，把脸放左上；想做意境/故事感，把人物放右下。
source:
  - wuwu composition.md（一方称）：https://www.iesdouyin.com/share/video/7654888893354986793
evidence: 仅 wuwu 一方称 → 薄弱，后续需补 NYIP 或学术来源（引用时作参考建议，非硬扣分依据）。
```

## C5. 天地比与水平线位置

```yaml
id: COMP-005
rule: 只有一根水平线时，想突出地景就天1地2，想突出天空/情绪就天2地1；风光片必须地平线水平。
why: 占比决定情绪——天空多=写意/情绪，地面多=写实/落脚；地平线歪斜直接拉低专业感。
how: 天空惨白却占一半时压低水平线让地面占2分；情绪片抬高水平线留天空；用机内电子水准仪校正地平线。
source:
  - wuwu 三分线/天地比（一方称）：https://www.iesdouyin.com/share/video/7654145039605435689 ；https://www.iesdouyin.com/share/video/7645615099033439497
  - 佳能《入门篇04》地平线要水平（已查证）：https://m.canon.com.cn/special/ds_abcbook/beginner04.html
  - 索尼《拍摄活力风景照》广角天空占比（已查证）：https://www.sony.com/zh-cn/electronics/support/e-mount-body-ilce-7-series/ilce-7m4/articles/00199911

```

## C6. 视线方向留白（鼻前空间）

```yaml
id: COMP-006
rule: 人脸朝右就把人放左三分线，人脸朝左就放右三分线，必须在视线前方留空间，不能把视线堵死。
why: 视线方向是一条隐形引导线，前方堵墙/贴边会让画面发闷、人物像要走出画面。
how: 人物贴视线方向边缘时，反向裁切或重拍，给视线方向留 1/3 以上空间。
source:
  - wuwu 视线留白（一方称）：https://www.iesdouyin.com/share/video/7631487948302634283 ；https://www.iesdouyin.com/share/video/7668627357791538451
  - NYIP/DataField 鼻前空间（一方称）：https://datafield.dev/photography/part-02/chapter-06/index.html
evidence: wuwu 一方称 + DataField 一方称 → 双一方称互证，可作规则。
```

## C7. 引导线与会聚线

```yaml
id: COMP-007
rule: 借道路/栏杆/河流/楼梯把视线引到主体，线条从画面边角出发、尽头指向主角；别把线条横卡在画面正中心。
why: 近大远小透视拉满纵深；人眼会自动顺着线性元素移动。
how: 画面平、缺纵深时凑近线条起点拍；线条横卡正中时挪步让线从边角入画；被引导到的主体落在中心点或三分点上。
source:
  - NYIP《Leading Lines》（已查证）：https://www.nyip.edu/photo-articles/photography-tutorials/leading-lines
  - 色影无忌《摄影师的眼力》（已查证）：https://info.xitek.com/favorites/201203/13-294727.html
  - wuwu 引导线（一方称）：https://www.iesdouyin.com/share/video/7637402569190427910 ；https://www.iesdouyin.com/share/video/7631487948302634283
evidence: NYIP 已查证 + wuwu 一方称 → 多源支撑。
```

## C8. 前景框架（搭画框）

```yaml
id: COMP-008
rule: 用近处的门框、树干、窗洞、拱门把远处主体框起来；框架歪一点、占画面 1/3~1/4 要透气、框架要比主角暗（暗框亮人）。
why: 框架天然引导视线穿过它看向中心，同时隔绝杂乱环境；太正太满会像证件照/监控画面。
how: 杂乱环境首选框架构图；框架太满太正时裁切或半遮；框架与人物同亮时压暗框架或等光；前景（花/玻璃/栏杆）必须与主题有关、要虚、只轻挡一点。
source:
  - NYIP 前景框架（已查证）：https://book.douban.com/subject/1007928/blockquotes （第183页）；https://info.xitek.com/favorites/201203/13-294727.html
```

## C9. 线条不穿人/穿头禁忌

```yaml
id: COMP-009
rule: 画面里的竖线（电线杆/栏杆/树干）只能分割面或引导视线，绝不能从人物身上穿过、把人物劈成两半；头部必须避开身后树干/路灯/栏杆。
why: 线一旦穿过主体，视觉上像"穿头/截肢"，是人像构图红线。
how: 发现电线杆、栏杆、树枝从人头/躯干穿过时，左右挪步或换机位让线落在人物一侧。
source:
  - wuwu 线不穿人（一方称）：https://www.iesdouyin.com/share/video/7681248699423476465

evidence: 仅 wuwu 一方称 → 但属视觉常识性硬伤，可作红线规则。
```

## C10. 视觉重力配重与留白

```yaml
id: COMP-010
rule: 把画面当天平——重物（花密色艳、山体、大块绿植）往下放或往一侧压，主体放到偏轻一侧配重；留白给想象空间，"东西越少情绪越重"。
why: 视觉上重物在上会头重脚轻；留白给观众想象空间。
how: 一侧色艳/花密导致失重时，把人物挪到轻的一侧三分线；想表达压抑用反向留白堵视线，想治愈用顺视线留白。
source:
```

## C11. 六种对比做减法（含长焦压缩/大光圈虚化去杂乱）

```yaml
id: COMP-011
rule: 主体要和环境"不一样"——明暗对比、色彩对比、虚实对比、大小对比、疏密对比、动静对比；背景杂乱时用长焦压缩或大光圈虚化把多面合并成少面。
why: 人眼对差异天生敏感；杂乱=面太多，压缩/虚化都是把多面合并成少面。
how: 画面平、主体不跳时，自问"主体和周围是否不一样"；不满足就开大光圈/换亮背景/放小人物/留一块空白；背景乱优先换长焦端或开大光圈，而非后期 P 掉。
source:
```

## C12. 对角线只用于动感

```yaml
id: COMP-012
rule: 对角线产生强动势，但只用在动感强的照片里；人脸作为视觉重点必须放三分点或中心点，不能放到取景框边缘。
why: 平行单线呆板，对角线引视线入画面深处；但人脸在边缘会被对角线张力带跑。
how: 静态人像/坐姿硬拉倾斜构图显别扭时回水平；动态跳跃/躺姿可用对角线且人脸上提至三分点。
source:
  - wuwu 对角线（一方称）：https://www.iesdouyin.com/share/video/7651913869006343470 ；https://www.iesdouyin.com/share/video/7631487948302634283
```

## C13. 广角畸变与人脸位置

```yaml
id: COMP-013
rule: 广角四角拉伸畸变——主要元素（人脸/半身）必须放画面中心防变形；次要元素（鞋、手脚、裙摆、发梢）放四角边缘拉伸显飘逸。
why: 广角透视近大远小，边缘放大最严重；人脸在边缘会变大鼻子/宽脸。
how: 广角人像脸歪/鼻子大时把脸挪回中心，裙摆/发梢留四角。
source:
  - wuwu 广角畸变（一方称）：https://www.iesdouyin.com/share/video/7624351655386975524 ；https://www.iesdouyin.com/share/video/7636683623042731305
```

## C14. 人像裁图铁律

```yaml
id: COMP-014
rule: 半身/七分身/九分身裁切时，绝不能卡在脖子、胯骨、膝盖、任何关节、脚踝上——特写裁胸口以上、近景裁胯骨以上、七分身裁大腿、九分身裁膝盖以下、全身留脚踝。
why: 裁关节=视觉上像截肢/断腿，显人窄短。
how: 点评人像时先看裁切位置；卡脖子/卡腰/卡膝盖的，顺延到下一个安全节点重裁或重拍。
source:
  - wuwu 裁图铁律（一方称）：https://www.iesdouyin.com/share/video/7647119193724194083 ；https://www.iesdouyin.com/share/video/7657475752950025522
evidence: 仅 wuwu 一方称 → 但属人像硬伤常识，可作红线。
```

## C15. 拍摄前自检清单（8问）

```yaml
id: COMP-015
rule: 按快门前依次问——主体放中心还是偏？拍大还是拍小？搭画框？用光突出？选焦点？会聚线？重复线？运动感？每条至少一个"是"再按快门。
why: 这8个问题覆盖了教材第8课全部突出主体的手段，是一个可执行的构图自检流程。
how: 把8问做成拍摄前的 mental checklist；点评时若画面元素太多主体不明，对照8问指出缺哪一问。
source:
  - NYIP 第8课8问（已查证）：https://book.douban.com/subject/1007928/blockquotes
evidence: NYIP 已查证 → 可作引擎自检流程。
```
