## S1. 鲜明主题与一图一主题

```yaml
id: SUB-001
rule: 一幅好照片必须有一个一眼可辨的鲜明主题（一个人、一件事或一个情节）；每张照片只表达一个视点/一个主题，不要试图在一张照片里塞多个意图。
why: 主题是照片存在的理由；观众若不能立刻看出"这张在拍什么"，构图用光再漂亮也失去意义；多主题等于无主题。
how: 按下快门前自问"这张我到底要表现什么"；若一句话说不清，就重新取景或放弃；旅行/环境人像先决定"这张要表现人还是表现环境"，再决定景别与构图。
source:
  - NYIP《Three Guidelines》鲜明主题（已查证）：https://www.nyip.edu/photo-articles/photography-tutorials/three-guidelines-for-great-photographs
  - NYIP 一幅照片一个主题（已查证）：https://book.douban.com/annotation/151016907/ （9.9）
  - wuwu 主题先行（一方称）：https://www.iesdouyin.com/share/video/7668627357791538451 ；https://www.iesdouyin.com/share/video/7647119193724194083

evidence: NYIP 已查证 + wuwu 一方称 → 多源硬支撑。
```

## S2. 精彩瞬间优先于完美构图

```yaml
id: SUB-002
rule: 当激动人心、出乎意料的瞬间出现时，先拍下来；之后再补拍一张构图更完美的。
why: 决定性瞬间错过不可复得，构图差可以靠裁切或第二张补救，反之不行。
how: 遇到突发事件先快速举机抓拍，不要等"布好阵"；事后若光线场景允许，再退后重新构图补一张。
source:
  - NYIP 精彩瞬间优先（已查证）：https://book.douban.com/subject/1007928/blockquotes （第28页）
evidence: NYIP 已查证 → 硬支撑。
```

## S3. 做减法排除干扰元素

```yaml
id: SUB-003
rule: 拍前多花两秒观察，剔除行人/广告牌/电线/杂物，只留一个核心主体；"七分拍三分修，千万别三分拍七分修"。
why: 杂讯是新手第一大病因；前期砍掉比后期 P 掉干净十倍；每多一个与主题无关的元素，就多一个竞争注意力的噪声点。
how: 元素太多主体不明时，建议换机位/长焦裁切/等路人走，而不是后期加滤镜掩盖；移动脚步换角度、用长焦裁掉背景杂人杂物、开大光圈虚化背景。
source:
  - NYIP 画面简洁（已查证）：https://www.nyip.edu/photo-articles/photography-tutorials/three-guidelines-for-great-photographs
```

## S4. 主体大小比例与景别

```yaml
id: SUB-004
rule: 让主体在画面中占足够大的比例，是突出重点最直接的手段；景别五档——远景交代环境、全景交代肢体、中景对话交流、近景肖像、特写放大局部；公众距离=疏离、社交距离=交流、亲密距离=情绪。
why: 尺寸本身就是视觉权重；脸占比决定情绪感染力；远景/全景里的脸太小，注意力被环境带走。
how: 想突出人物情绪却拍成远景/中景的，要求走近换近景或特写；向前走几步或换更长焦段让主体充满画面。
source:
  - NYIP 主体大小比例（已查证）：https://book.douban.com/annotation/75651566/ ；https://info.xitek.com/favorites/201203/13-294727.html
```

## S5. 光的三特征与硬柔光

```yaml
id: SUB-005
rule: 任何光都有三个可被控制的维度——明暗度、方向、色彩；硬光（晴天太阳、聚光灯）方向性强、阴影边缘锐利、反差大，擅长塑形；柔光（阴天、窗纱后、大面积漫射）阴影柔和、反差小，擅长表现皮肤。
why: 明暗决定曝光基础，方向决定立体与阴影，色彩决定情绪与白平衡基调；光源相对面积决定软硬。
how: 拍摄前观察"光多亮、从哪来、什么色温"；要质感/力量感用硬光；要美人/细腻皮肤用柔光或拉远光源、加漫射。
source:
  - NYIP 光的三个基本特征（已查证）：https://book.douban.com/annotation/151016907/ （9.2）
  - NYIP 硬光与柔光（通识）：http://www.etc.edu.cn/ko/3f220f26b4c74f4fa13d202ccade52f2 ；http://www.tup.tsinghua.edu.cn/upload/books/yz/097745-01.pdf
evidence: NYIP 已查证+通识 → 多源支撑。
```

## S6. 光线方向：顺/45°侧/90°侧/逆光

```yaml
id: SUB-006
rule: 正面光（平光）把主体全部照亮、几乎无阴影，但画面扁平缺层次；45°侧光是室外人像最佳光线——明暗均衡、立体感好；90°侧光造成强烈明暗对半分割，适合戏剧性/质感；逆光下对背景测光得剪影、对人脸测光得轮廓光。
why: 立体感靠明暗交界线塑造；没有阴影就没有体积；45°角同时保留受光面细节和阴影面体积。
how: 要遮瑕/美妆记录可用顺光；要立体感人像把人物转 45°；拍男性硬朗肖像、建筑纹理用 90°侧光；要剪影对亮背景测光，要保人脸细节对人脸点测光或反光板补。拍人像优先选日出后1-2小时或日落前1-2小时。
source:
  - NYIP 正面光（已查证）：https://book.douban.com/annotation/151016907/ （9.4）
  - NYIP 45°侧光（已查证）：https://book.douban.com/annotation/151016907/ （9.5）
  - NYIP 90°侧光（已查证）：https://book.douban.com/annotation/151016907/ （9.6）
  - NYIP 逆光剪影与轮廓光（已查证）：https://book.douban.com/annotation/151016907/ （9.7）
  - 佳能《人像-用光与背景》（已查证）：https://www.canon.com.cn/special/canon_portrait/1.html

```

## S7. 室外人像避直射光选漫射

```yaml
id: SUB-007
rule: 室外人像不要让被摄者站在直射阳光下；优先选阴天、云遮日的漫射光，或把人移到阴影处。
why: 直射硬光造成眼窝鼻下死黑阴影、眯眼、皮肤油光；漫射光下阴影柔和、表情自然。
how: 找树荫/建筑阴影处拍人；注意树荫下漏下来的光斑会在脸上形成花斑，需避开或让人物稍挪位置。
source:
  - NYIP 室外人像避免直射阳光（已查证）：https://book.douban.com/annotation/151016907/ （9.9）
evidence: NYIP 已查证 → 硬支撑。
```

## S8. 美姿破面与摆姿口诀

```yaml
id: SUB-008
rule: 把人体拆成脸面/胸面/腿面三大面，三面不能同处一个平面（脸正胸就得侧），也不能同时都侧；只要有一个面跟其他两个不在同一平面即可。摆姿口诀：正脸低头、侧脸抬头、背面回头；高机位要摆头、低机位要探头。机位三档：低机位拍全身显腿长、中机位拍半身亲切、高机位拍近景突出面部情绪。
why: 三面全正=站军姿/证件照；破面才有 S 曲线和层次；机位高度决定透视——仰拍腿长、俯拍脸小。
how: 站姿僵硬像证件照时，要求模特转脸/侧身/扭胯/弯腿打破正面；全身显五五分要求蹲低仰拍；近景显胖要求抬高机位俯拍。
```

## S9. 眼神与情绪引导

```yaml
id: SUB-009
rule: 模特眼神直盯镜头会丢 3/4 美感；先让眼神避开镜头（眺望远方/低头/侧脸），并给具体"剧本"（闻一下/抱起来亲一个/假笑一个）进入角色；好片外在可修、眼神修不出。
why: 眼神是照片灵魂；呆板眼神多因摄影师没引导情绪。
how: 人像像证件照/眼神空洞时，重拍时给情景指令而非让模特"笑一个"；故事感给眼神、氛围感吹发丝。
```

## S10. 焦段画面感

```yaml
id: SUB-010
rule: 广角=近大远小张力、长焦=空间压缩聚拢、标准=人眼平和；口诀"拍风光用超广、拍远景用长焦、拍旅行用24、拍纪实用35、拍小孩用50、拍妹子用85"；人像焦段：全身35、半身50、特写85、局部200。
why: 焦段不只是取景范围，更决定情绪——夸张用超广、情绪用长焦、日常记录用标准；广角镜头夸大近大远小、拉开距离感；长焦镜头压缩空间、让前后物体贴在一起。
how: 人景融合好但脸不突出→换85；环境氛围不够→换35/24；广角片人脸放四角变形时把脸挪回中心；要表现空旷/孤独用广角低角度，要拍压缩感的人群/山峦叠层用长焦。
```

## S12. 扫街与花海时机参数

```yaml
id: SUB-012
rule: 清晨/日落前一小时黄金时段，找一处光比大的机位架稳，耐心等行人/车辆走进光影框架再按快门；花海只用顺光（干净通透）或侧逆光（太阳在模特身后45°），全程点测人脸锁曝光，逆光加+0.3~+0.7档补偿，色温5500K以上偏暖。
why: 好作品靠提前观察+预判+等待；侧逆光勾发丝和肩颈线条；点测人脸才能保肤色不被花海亮部带飞。
```
