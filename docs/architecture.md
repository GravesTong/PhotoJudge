# 产品架构与依据说明

## 一、产品定位

输入照片 → 输出"看得懂、改得动"的结构化诊断报告。目标人群：普通拍照者、摄影新手、想系统复盘作品的进阶者。

## 二、整体架构

```
输入（照片 + 题材/用途）
  ↓
① 六维分析层（视觉理解 + 规则）
  构图 / 曝光 / 对焦清晰度 / 色彩白平衡 / 内容主体 / 后期建议
  ↓
② 规则引擎（核心资产 · 可解释打分）
  六维分项打分 → 题材权重加权 → 0–10 总评分 + 等级
  ↓
③ 诊断报告输出
  总评 / 分项 / 问题清单 / 修改动作 / 后期方案 / 视觉标注
```

## 三、六维诊断维度

1. 构图 —— 三分法/九宫格、主体位置、水平线、引导线、留白、裁切。
2. 曝光 —— 明暗分布、高光溢出/阴影死黑、直方图、补偿建议。
3. 对焦与清晰度 —— 锐利度、景深、模糊/抖动。
4. 色彩与白平衡 —— 白平衡偏移、色调、饱和度、和谐。
5. 内容与主体 —— 主体突出、干扰元素、叙事。
6. 后期建议 —— 六维问题 → 可执行修图动作。

## 四、评分与权重

- 0–10 分 + 等级，每维分项分。
- 题材权重默认值（待 `rules/` 核验）：
  - 人像：构图30 / 曝光25 / 对焦20 / 色彩15 / 内容10
  - 风光：曝光30 / 构图25 / 色彩25 / 对焦10 / 内容10
  - 其他：五维均衡各20

## 五、产品硬约束

- 评分可解释（每条给"为什么 + 怎么改"）。
- 不评判主观审美/风格好坏。
- 不做 AI 生成图 vs 真实照片鉴定。
- 视觉标注忠于原图真实位置，不重绘。
- 后期参数口径区分手机与电脑设备。

## 六、规则依据（来源，采集中）

`rules/` 填充依据以下四类来源，每条规则标注来源与证据等级（已查证 / 一方称 / 通识）：

1. `wuwu-photography` 本地摄影教学库 —— 构图/影调调色/人像实战（中文实战规则）。
2. 《纽约摄影学院教材》 —— 构图、曝光、景深、用光底层逻辑。
3. Adobe Lightroom / Photoshop 官方教程 —— 后期参数操作口径（EV、高光/阴影、色温、锐化、去噪等）。
4. 佳能、索尼官方教学 —— 参数与实战场景对应。

交叉综合：同一规则的多来源支撑已并入规则条目；来源间口径差异已收敛为引用规则（条件分支 / 命名并存 / 设备边界），见 `rules/conflicts.md`。
